
# Nexa v1 🤖

An Arduino robot built by Harmain and Asfiya. It avoids obstacles using an ultrasonic sensor on a servo, shows an animated face on a TFT display, and plays sounds through a speaker.

## 🎥 Demo
[▶️ Watch Nexa on YouTube]((https://youtube.com/shorts/ezcM6d-XtlA?si=f7ceIGTOJB1TVXtO))

## 🔧 Hardware
Arduino Uno · L298N motor driver · DC motors · Ultrasonic sensor + SG90 servo · TFT display · DFPlayer Mini + speaker
